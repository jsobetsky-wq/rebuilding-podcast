# Tools Setup Guide

Everything you need installed and configured to produce the podcast.

---

## Required Tools

### 1. ffmpeg (Audio/Video Processing)
All the audio and video scripts require ffmpeg.

**Windows (winget):**
```bash
winget install Gyan.FFmpeg
```

**Windows (manual):**
1. Download from https://ffmpeg.org/download.html
2. Extract to `C:\ffmpeg`
3. Add `C:\ffmpeg\bin` to your system PATH

**Verify:**
```bash
ffmpeg -version
```

### 2. Node.js (Website)
Already installed (v24). Used for the Next.js website.

### 3. Git (Version Control)
Already installed. Used to push changes that trigger deployments.

### 4. Riverside.fm (Recording)
- Sign up at https://riverside.fm
- Choose the plan with WAV downloads and transcription
- Set up: Audio-only recording mode, WAV quality, local recording enabled
- Create a recurring session template for weekly recordings

## Recommended Tools

### Audio Editing
If you need more control than the automated scripts:

**Audacity** (Free, open source)
- Download: https://www.audacityteam.org
- Good for: manual cuts, removing specific sections, detailed noise reduction
- Learning curve: Low

**Descript** (Paid, $24/mo)
- Download: https://www.descript.com
- Good for: edit audio by editing text (transcription-based), AI filler word removal
- Learning curve: Very low — game changer for solo podcasters

### Video/Shorts Editing
For more polished shorts beyond the ffmpeg scripts:

**CapCut** (Free)
- Download: https://www.capcut.com
- Good for: vertical video editing, auto-captions, transitions, effects
- Best for: Instagram Reels, TikTok, YouTube Shorts
- Learning curve: Low

**DaVinci Resolve** (Free)
- Download: https://www.blackmagicdesign.com/products/davinciresolve
- Good for: professional video editing, color grading, audio mixing
- Best for: YouTube long-form content, polished shorts
- Learning curve: Medium-High (powerful but complex)

**Canva Video** (Free/$13/mo)
- https://www.canva.com
- Good for: quick audiogram videos, social clips with text overlays
- Best for: fast production, no editing experience needed

### Graphics
For custom graphics beyond the HTML templates:

**Canva** (Free/$13/mo)
- https://www.canva.com
- Good for: episode covers, social cards, YouTube thumbnails
- Templates available — search "podcast" for starting points

**Figma** (Free)
- https://www.figma.com
- Good for: precise design work, brand consistency
- Worth learning if you want full control over visuals

### Podcast Hosting
You need a hosting provider to store audio files and distribute your RSS:

**Buzzsprout** ($12-24/mo) — Recommended
- Simple, reliable, good analytics
- Auto-distributes to Apple, Spotify, etc.
- Includes a basic website (you already have a better one)

**Podbean** ($9-29/mo)
- Good analytics, monetization options
- Unlimited storage on paid plans

**Anchor/Spotify for Podcasters** (Free)
- Free hosting, owned by Spotify
- Limited analytics, less control

### Transcription (for captions/subtitles)
- **Riverside.fm** — Built-in transcription with your recording
- **Descript** — Edit-by-transcript workflow
- **Otter.ai** — Dedicated transcription ($8.33/mo)
- **YouTube** — Auto-generates captions on upload (free, decent quality)

## Directory Structure for Assets

Create these directories for your production files:
```
assets/
  raw/              # Raw recordings from Riverside (WAV)
  audio/            # Intro/outro music files
    intro.mp3
    outro.mp3
  subtitles/        # SRT files for captions
  graphics/         # Generated cover art, social cards, thumbnails

output/             # Generated by scripts (git-ignored)
  episodes/         # Final processed MP3s
  clips/            # Extracted audio clips
  shorts/           # Generated short videos
  videos/           # Generated audiograms
  normalized/       # Batch-normalized files
```

### Create the directories:
```bash
mkdir -p assets/raw assets/audio assets/subtitles assets/graphics
mkdir -p output/episodes output/clips output/shorts output/videos output/normalized
```

### Add to .gitignore:
The `output/` directory and `assets/raw/` should be git-ignored (large files).
The `assets/audio/` intro and outro files should be committed.

## First-Time Setup Checklist

- [ ] Install ffmpeg and verify it works (`ffmpeg -version`)
- [ ] Create asset directories (see above)
- [ ] Sign up for Riverside.fm and configure recording settings
- [ ] Choose a podcast hosting provider and create account
- [ ] Find/create intro and outro music (save to `assets/audio/`)
- [ ] Generate main podcast cover art using `scripts/graphics/generate-podcast-cover.html`
- [ ] Submit podcast cover art and description to hosting provider
- [ ] Test the full workflow with a practice recording
- [ ] Run `scripts/audio/process-episode.sh` on the test recording
- [ ] Verify the RSS feed works at your website's `/api/feed` endpoint
